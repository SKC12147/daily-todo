DAILY TO-DO LIST — ANDROID

Features
- Add tasks for today
- Mark tasks complete
- Filter All / To do / Done
- Delete tasks or clear completed tasks
- Automatically saves on this device; no account needed
- Today's list starts fresh on the next date

IMPORTANT: This is an installable web app (PWA), not a signed APK.

EASIEST WAY TO USE IT
1. Put the daily_todo_app folder on a website that supports HTTPS (for example, a static site host).
2. Open that HTTPS site in Google Chrome on your Android phone.
3. Tap the Chrome menu (⋮) and choose “Install app” or “Add to Home screen”.
4. Open Daily To-Do from your home screen.

For a quick preview, open index.html in a browser. Installation and offline caching require hosting over HTTPS (or localhost).

DATA NOTE
Tasks are stored in the browser's local storage on the phone. Clearing browser site data can erase them. The app does not sync tasks between devices.
